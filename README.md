# 暖光家 LightHome｜适老化智能照明 App 交互原型

这是用于产品经理求职作品集展示的 **C 端智能照明 App 高保真交互原型**。

- 在线体验地址（需先在 GitHub Settings → Pages 开启后生效）：https://swq-lrq.github.io/LightHome-Prototype/
- 原型版本：V0.9.1
- 演示内容：设备添加与配对、灯光开关/亮度调节、场景配置、定时计划、异常提示与适老化设置。

> **说明**：这是静态前端交互原型，模拟设备配对、灯光反馈、定时任务与日志，不代表已连接真实灯具或产品已正式上线。

## GitHub Pages 发布步骤

1. 将本文件夹的 `index.html` 与 `README.md` 上传至 GitHub 仓库 `SWQ-LRQ/LightHome-Prototype` 的 `main` 分支根目录。
2. 打开仓库 `Settings → Pages`。
3. 在 `Build and deployment` 中，`Source` 选 `Deploy from a branch`；`Branch` 选 `main`，文件夹选 `/ (root)`，然后点击 `Save`。
4. 等待 GitHub Pages 显示公开访问地址，再从手机移动网络测试链接。
